# Toxic880/tap

Homebrew tap for [TwistPad](https://github.com/Toxic880/TwistPad).

```bash
brew install --cask Toxic880/tap/twistpad
```

TwistPad is not notarized. If macOS blocks it on first launch, either use
**System Settings > Privacy & Security > Open Anyway**, or install with
`--no-quarantine` to skip that:

```bash
brew install --cask --no-quarantine Toxic880/tap/twistpad
```
